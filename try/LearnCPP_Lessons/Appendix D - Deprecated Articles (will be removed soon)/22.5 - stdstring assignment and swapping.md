**String assignment**

The easiest way to assign a value to a string is to use the overloaded operator= function. There is also an assign() member function that duplicates some of this functionality.

|**string& string::operator= (const string& str)**  <br/>**string& string::assign (const string& str)**  <br/>**string& string::operator= (const char* str)**  <br/>**string& string::assign (const char* str)**  <br/>**string& string::operator= (char c)**  <br/>- These functions assign values of various types to the string.<br/>- These functions return *this so they can be "chained�.<br/>- Note that there is no assign() function that takes a single char.<br/>Sample code:<br/> `std::string sString; // Assign a string value sString = std::string("One"); <br/>std::cout << sString << '\n'; const std::string sTwo("Two"); sString.assign(sTwo); <br/>std::cout << sString << '\n'; // Assign a C-style string sString = "Three"; <br/>std::cout << sString << '\n'; sString.assign("Four"); std::cout << sString <br/><< '\n'; // Assign a char sString = '5'; std::cout << sString << '\n'; // Chain <br/>assignment std::string sOther; sString = sOther = "Six"; std::cout << sString <br/><< ' ' << sOther << '\n';` <br/>Output:<br/> `One Two Three Four 5 Six Six`|

The assign() member function also comes in a few other flavors:

|**string& string::assign (const string& str, size_type index, size_type len)**<br/>- Assigns a substring of str, starting from index, and of length len<br/>- Throws an out_of_range exception if the index is out of bounds<br/>- Returns *this so it can be "chained�.<br/>Sample code:<br/> `const std::string sSource("abcdefg"); std::string sDest; sDest.assign(sSource, <br/>2, 4); // assign a substring of source from index 2 of length 4 std::cout << <br/>sDest << '\n';` <br/>Output:<br/> `cdef`|

|**string& string::assign (const char* chars, size_type len)**<br/>- Assigns len characters from the C-style array chars<br/>- Throws an length_error exception if the result exceeds the maximum number of characters<br/>- Returns *this so it can be "chained�.<br/>Sample code:<br/> `std::string sDest; sDest.assign("abcdefg", 4); std::cout << sDest << '\n';` <br/> <br/>Output:<br/> `abcd` <br/>This function is potentially dangerous and its use is not recommended.|

|**string& string::assign (size_type len, char c)**<br/>- Assigns len occurrences of the character c<br/>- Throws a length_error exception if the result exceeds the maximum number of characters<br/>- Returns *this so it can be "chained�.<br/>Sample code:<br/> `std::string sDest; sDest.assign(4, 'g'); std::cout << sDest << '\n';` <br/>Output:<br/> `gggg`|

**Swapping**

If you have two strings and want to swap their values, there are two functions both named swap() that you can use.

|**void string::swap (string& str)**  <br/>**void swap (string& str1, string& str2)**<br/>- Both functions swap the value of the two strings. The member function swaps *this and str, the global function swaps str1 and str2.<br/>- These functions are efficient and should be used instead of assignments to perform a string swap.<br/>Sample code:<br/> `std::string sStr1("red"); std::string sStr2("blue"); std::cout << sStr1 << <br/>' ' << sStr2 << '\n'; swap(sStr1, sStr2); std::cout << sStr1 << ' ' << sStr2 <br/><< '\n'; sStr1.swap(sStr2); std::cout << sStr1 << ' ' << sStr2 << '\n';` <br/>Output:<br/> `red blue blue red red blue`|

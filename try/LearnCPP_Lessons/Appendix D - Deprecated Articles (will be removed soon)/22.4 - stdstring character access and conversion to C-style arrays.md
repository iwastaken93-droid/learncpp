**Character access**

There are two almost identical ways to access characters in a string. The easier to use and faster version is the overloaded operator\[\]:

|**char& string::operator[] (size_type nIndex)**  <br/>**const char& string::operator[] (size_type nIndex) const**<br/>- Both of these functions return the character with index nIndex<br/>- Passing an invalid index results in undefined behavior<br/>- Because char& is the return type, you can use this to edit characters in the array<br/>Sample code:<br/> `std::string sSource{ "abcdefg" }; std::cout << sSource[5] << '\n'; sSource[5] <br/>= 'X'; std::cout << sSource << '\n';` <br/>Output:<br/> `f abcdeXg`|

There is also a non-operator version. This version is slower since it uses exceptions to check if the nIndex is valid. If you are not sure whether nIndex is valid, you should use this version to access the array:

|**char& string::at (size_type nIndex)**  <br/>**const char& string::at (size_type nIndex) const**<br/>- Both of these functions return the character with index nIndex<br/>- Passing an invalid index results in an out_of_range exception<br/>- Because char& is the return type, you can use this to edit characters in the array<br/>Sample code:<br/> `std::string sSource{ "abcdefg" }; std::cout << sSource.at(5) << '\n'; sSource.at(5) <br/>= 'X'; std::cout << sSource << '\n';` <br/>Output:<br/> `f abcdeXg`|

**Conversion to C-style arrays**

Many functions (including all C functions) expect strings to be formatted as C-style strings rather than std::string. For this reason, std::string provides 3 different ways to convert std::string to C-style strings.

|**const char* string::c_str () const**<br/>- Returns the contents of the string as a const C-style string<br/>- A null terminator is appended<br/>- The C-style string is owned by the std::string and should not be deleted<br/>Sample code:<br/> `#include  std::string sSource{ "abcdefg" }; std::cout << std::strlen(sSource.c_str());` <br/> <br/>Output:<br/> `7`|

|**const char* string::data () const**<br/>- Returns the contents of the string as a const C-style string<br/>- A null terminator is appended. This function performs the same action as `c_str()` <br/>- The C-style string is owned by the std::string and should not be deleted<br/>Sample code:<br/> `#include  std::string sSource{ "abcdefg" }; const char* szString{ "abcdefg" }; // memcmp <br/>compares the first n characters of two C-style strings and returns 0 if they <br/>are equal if (std::memcmp(sSource.data(), szString, sSource.length()) == 0) <br/>std::cout << "The strings are equal"; else std::cout << "The strings are not <br/>equal";` <br/>Output:<br/> `The strings are equal`|

|**size_type string::copy(char* szBuf, size_type nLength, size_type nIndex = 0) const**<br/>- Both flavors copy at most nLength characters of the string to szBuf, beginning with character nIndex<br/>- The number of characters copied is returned<br/>- No null is appended. It is up to the caller to ensure szBuf is initialized to NULL or terminate the string using the returned length<br/>- The caller is responsible for not overflowing szBuf<br/>Sample code:<br/> `std::string sSource{ "sphinx of black quartz, judge my vow" }; char szBuf[20]; int nLength{ static_cast(sSource.copy(szBuf, 5, 10)) }; szBuf[nLength] = '\0'; // Make sure we terminate <br/>the string in the buffer std::cout << szBuf << '\n';` <br/>Output:<br/> `black`|

This function should be avoided where possible as it is relatively dangerous (as it is up to the caller to provide null-termination and avoid buffer overflows).

**Inserting**

Inserting characters into an existing string can be done via the insert() function.

|**string& string::insert (size_type index, const string& str)**  <br/>**string& string::insert (size_type index, const char* str)**<br/>- Both functions insert the characters of str into the string at index<br/>- Both function return *this so they can be "chained�.<br/>- Both functions throw out_of_range if index is invalid<br/>- Both functions throw a length_error exception if the result exceeds the maximum number of characters.<br/>- In the C-style string version, str must not be NULL.<br/>Sample code:<br/> `string sString("aaaa"); cout << sString << endl; sString.insert(2, string("bbbb")); <br/>cout << sString << endl; sString.insert(4, "cccc"); cout << sString << endl;` <br/> <br/>Output:<br/> `aaaa aabbbbaa aabbccccbbaa`|

Here's a crazy version of insert() that allows you to insert a substring into a string at an arbitrary index:

|**string& string::insert (size_type index, const string& str, size_type startindex, size_type num)**<br/>- This function inserts num characters str, starting from startindex, into the string at index.<br/>- Returns *this so it can be "chained�.<br/>- Throws an out_of_range if index or startindex is out of bounds<br/>- Throws a length_error exception if the result exceeds the maximum number of characters.<br/>Sample code:<br/> `string sString("aaaa"); const string sInsert("01234567"); sString.insert(2, <br/>sInsert, 3, 4); // insert substring of sInsert from index [3,7) into sString <br/>at index 2 cout << sString << endl;` <br/>Output:<br/> `aa3456aa`|

There is a flavor of insert() that inserts the first portion of a C-style string:

|**string& string::insert(size_type index, const char* str, size_type len)**<br/>- Inserts len characters of str into the string at index<br/>- Returns *this so it can be "chained�.<br/>- Throws an out_of_range exception if the index is invalid<br/>- Throws a length_error exception if the result exceeds the maximum number of characters.<br/>- Ignores special characters (such as �)<br/>Sample code:<br/> `string sString("aaaa"); sString.insert(2, "bcdef", 3); cout << sString << <br/>endl;` <br/>Output:<br/> `aabcdaa`|

There's also a flavor of insert() that inserts the same character multiple times:

|**string& string::insert(size_type index, size_type num, char c)**<br/>- Inserts num instances of char c into the string at index<br/>- Returns *this so it can be "chained�.<br/>- Throws an out_of_range exception if the index is invalid<br/>- Throws a length_error exception if the result exceeds the maximum number of characters.<br/>Sample code:<br/> `string sString("aaaa"); sString.insert(2, 4, 'c'); cout << sString << endl;` <br/> <br/>Output:<br/> `aaccccaa`|

And finally, the insert() function also has three different versions that use iterators:

|**void insert(iterator it, size_type num, char c)**  <br/>**iterator string::insert(iterator it, char c)**  <br/>**void string::insert(iterator it, InputIterator begin, InputIterator end)**<br/>- The first function inserts num instances of the character c before the iterator it.<br/>- The second inserts a single character c before the iterator it, and returns an iterator to the position of the character inserted.<br/>- The third inserts all characters between [begin,end) before the iterator it.<br/>- All functions throw a length_error exception if the result exceeds the maximum number of characters.|
